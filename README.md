# MotoNav 🏍️🧭

MotoNav is a feature-rich Android navigation and companion app designed specifically for motorcycle riders. Built with modern Android development practices, Jetpack Compose, and Material 3.

## Features

- **Advanced Navigation & Routing**: Fastest and scenic route planning, turn-by-turn guidance, and live location selection.
- **Bike Garage**: Manage your motorcycle details, maintenance, and setup.
- **Fuel Calculator & Station Finder**: Calculate trip fuel costs, efficiency estimates, and find nearby fuel stations.
- **Explore Scenic Places**: Discover breathtaking rides, waypoints, and scenic destinations.
- **Ride History & Tracking**: Log your past rides, routes, and statistics.
- **Rider Community & Photos**: Share ride photos, view photo maps, and connect with fellow riders.
- **Offline & Secure Local Storage**: Powered by Room Database and DataStore.

## Tech Stack

- **UI**: Jetpack Compose, Material 3
- **Architecture**: MVVM (Model-View-ViewModel), Repository Pattern
- **Database**: Room, DataStore
- **Language**: Kotlin

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/srizz49/motonav.git
   ```
2. Open the project in [Android Studio](https://developer.android.com/studio).
3. Sync project with Gradle files and run on an Android emulator or physical device.
